# 사내 의견함 정리 도우미 (HR 분류 AI)

직원이 남긴 의견 한 줄을 읽고 **칸**(급여 · 복지 · 조직문화 · 리더십 · 안전보건 · 온보딩 · 평가 · 기타)과 **긴급도**(높음 · 보통 · 낮음), **이유 한 줄**을 알려 주는 분류기입니다. 인사팀이 받아서 담당자에게 배정하는 일을 돕는 데모입니다.

- 써 보기: https://my-classifier-alpha.vercel.app/
- 모든 문장과 데이터는 **지어낸 연습용**입니다. 실제 회사 · 사람 · 제품과 관계없습니다.
- 이 도구는 AI의 **추정**을 보여 줍니다. 최종 확인은 사람이 합니다.

## 다섯 가지 화면
| 탭 | 하는 일 |
|---|---|
| 분류 | 의견 한 줄을 보내면 칸 · 긴급도 · 이유가 대화처럼 이어집니다. 아래의 «여러 줄 한 번에 분류»에서는 의견 여러 줄(붙여넣기 · CSV)을 묶어서 분류하고, 끝나면 대시보드로 넘어갑니다. |
| 채점 | 정답 30개로 규칙과 AI의 점수를 나란히 잽니다. 내 CSV(의견 · 칸 · 긴급도)로도 잴 수 있습니다. |
| 대시보드 | 분류한 결과(처음에는 예시 데이터)를 연 · 월별 접수, 칸별 분포, 먼저 볼 문장, 처리 단계(접수 → 담당자 배정 → 처리 중 → 처리 완료), 담당자 배정 메일 본문 복사를 보여 줍니다. |
| 담당자별 | 대시보드의 결과를 담당자 이름별로 모아서, 담당자마다 처리 안 된 것 · 긴급 높음 · 기한 넘김을 보여 주고 «보낼 글»을 만들어 줍니다. 칸마다 담당자 이름을 적어 두면 같은 이름은 한 사람으로 묶입니다. |
| 운영 결산 | 대시보드와 같은 자료를 연도별로 세어 한 해 요약 · 월별 추이 · 운영 점검표(목표는 직접 입력) · 칸별 결산을 보여 주고, 총괄자가 문의 성격(단순 문의 · 업무 오류 · 응대 문제 · 제도·시스템·외부 · 현업 팀장·팀원)과 귀책 · 중대성(상·중·하)을 확정해 담당자별 평가 점수(예시)를 계산합니다. 총괄자가 적은 값은 이 브라우저에만 저장되고 서버로 가지 않습니다. 점수와 등급은 참고용이며 최종 평가는 사람이 합니다. |

## 어떻게 만들었나
1. **판단 기준을 먼저 적었습니다.** 칸의 뜻, 긴급도의 뜻, 애매한 경우의 기준 10여 개를 `데이터명세.md`와 `criteria.json`에 적었습니다.
2. **가장 나쁜 실수를 정했습니다.** 다칠 위험이 있는 안전보건, 급여 누락, 조직문화에서 사람이 피해를 입는 문제를 놓치는 것입니다. 점수와 별도로 따로 셉니다.
3. **정답은 사람이 붙였습니다.** 채점용 30개의 정답은 AI의 의도를 가린 채 직접 붙였고(11개가 갈렸습니다), 그중 4개는 판단 기준을 정한 뒤 기준에 맞게 고쳤습니다.
4. **규칙 기준선을 먼저 재고 AI와 비교했습니다.** 낱말 규칙만 쓴 기준선보다 AI가 얼마나 나은지 숫자로 봅니다.

## 점수 (지어낸 문장 30개 기준)
| 방식 | 칸 | 긴급도 | 가장 나쁜 실수 놓침 |
|---|---|---|---|
| 낱말 규칙만 | 15 / 30 | 14 / 30 | 5 / 5 |
| AI(Gemini), 한 줄씩 보냄 | 27~28 / 30 | 22~23 / 30 | 0~1 / 5 |
| AI(Gemini), 10개씩 묶어 보냄 | 29 / 30 | 24 / 30 | — |

조건: 모델 gemini-3.5-flash-lite, 지시문 p2, 판단 기준 criteria.json version 1. 한 줄씩 보낸 결과는 3회 채점의 범위이고 묶음은 1회 채점입니다. 같은 조건으로 다시 재도 몇 개씩 흔들립니다.
«사람 확인» 표시: 같은 문장을 두 번 분류해 결과가 다르면 표시합니다. 틀린 10개 중 4개를 잡았고 맞는 문장을 잘못 표시한 것은 없었지만, 나머지 6개는 놓칩니다.

## 한계
- **검증이 작습니다.** 지어낸 문장 30개에서 잰 점수이고, 정답은 한 사람의 판단입니다. 실제 의견에서도 같다는 보장이 없습니다.
- **긴급도는 사람마다 갈립니다.** AI는 «높음»을 «보통»으로 낮춰 매기는 경향이 있었습니다.
- **칸은 8개로 고정**되어 있습니다. 회사마다 칸이 다르면 판단 기준과 예시를 다시 만들고 다시 검증해야 합니다.
- **무료 구간입니다.** 하루 · 분당 사용 횟수에 한도가 있어서, 넘으면 «오늘은 끝났어요»가 나옵니다.

## 개인정보와 보안을 어떻게 다뤘나
- 브라우저에서 AI로 보내기 전에 **이름 · 전화번호 · 사번 · 이메일 · 주민번호 · 카드 · 계좌 · 주소를 가립니다.** (`mask.js`, `api/_core.py`)
- 넣은 문장과 분류 결과는 **서버에 저장하지 않습니다.** 대시보드의 결과는 화면에만 있고, 내려받은 CSV를 다시 올려 이어서 봅니다.
- Gemini 키는 서버 환경 변수에만 있고 화면 코드와 저장소에는 없습니다.
- 하루 · 분당 한도는 서버에서 셉니다(Upstash Redis).
- **실제 회사 · 개인 정보는 넣지 마세요.** 무료 구간의 입력은 제공사 정책에 따라 쓰일 수 있으니, 실제 의견에 쓰려면 약관과 회사 정책을 먼저 확인해야 합니다.

## 폴더
```
index.html style.css app.js      분류 · 채점 화면

mask.js rules.js                 개인정보 가리기, 낱말 규칙(기준선)
criteria.json keywords.json      칸의 뜻과 순서 · 판단 기준 / 규칙이 쓰는 낱말
examples.json sample.json        지시문 예시 / 대시보드 · 운영 결산 예시 데이터
settle.js settle.css             운영 결산 탭
eval/answer.json                 채점용 정답 30개
api/classify.py                  Vercel 서버 조각 (Gemini 호출)
api/_core.py _service.py _limit.py  지시문 · 가리기 · 한도
dev_server.py score_ai.py        내 컴퓨터에서 실행 · 점수 재기
데이터명세.md CLAUDE.md            판단 기준 · 작업 규칙
```

## 내 컴퓨터에서 실행
1. `.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY`를 채웁니다. (`.env`는 올리지 않습니다)
2. `python dev_server.py` 후 http://localhost:8000 을 엽니다. (Python 3, 추가 설치 없음)
3. 점수 재기: `python score_ai.py 2` (정답 파일 `data/answer.json`이 필요합니다. 같은 내용이 `eval/answer.json`에 있으니 복사해서 쓰세요.)

## Vercel에 올리기
저장소를 Import(Preset: Other)하고 환경 변수 `GEMINI_API_KEY`, `GEMINI_MODEL`, `DAILY_LIMIT`, `MINUTE_LIMIT`을 넣습니다. 하루 한도 저장소로 Upstash Redis를 연결합니다.
